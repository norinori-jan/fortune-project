# 易の辞書（真勢易秘訣より・要約）

`eki_dict.csv` … table-pad で開く表（UTF-8 BOM）。1行＝卦×質問。

列: 卦番号 / 卦名 / よみ / 上卦 / 下卦 / 分野 / 相談の言い方 / 質問 / 判定 / 一言 / 内容 / 探しやすい言葉 / 出典 / 奇門遁甲の事項 / 奇門で見る所

- 分野 → 相談の言い方 → 質問 の3段で、ふだんの言葉で引けるようにしている
- 判定: 吉 / やや吉 / 条件付き / 凶 / 注意 / 不明（読み取った本文からの判断）
- 内容は原文の逐語ではなく要約。出典はページ
- 「奇門で見る所」は一般知識による仮置き（要確認）
- 追加は同名ファイルの上書きで行う（卦番号順）

## 2. いま動いているつながり（確認済み）

| つながり | 中身 | 確認 |
|---|---|---|
| Raw → 読み込み | `engine/lopan_service.py` が Raw（層10〜27）を読む | 18層すべて読み込めた |
| 角度 → 各層の記載 | `measure(330.0)` | 引ける層と、引けない理由は §3 |
| 羅盤 → 知識辞書 | `data/dict-pack_lopan.json`（20件）を辞書に入れる | 知識辞書に取り込み、「羅盤」「層10」「measure」で検索できた（19件・JSエラーなし） |
| 羅盤 → ai-hub | 同じ辞書パック形式（dict-pack v1）。ai-hub が読む辞書パックに混ぜる | 形式は同じ。ai-hub での読み込みは **未確認** |

### 辞書に入れる手順（知識辞書）
設定 → 辞書パック → ファイルを選ぶ → `dict-pack_lopan.json`。入ったら、検索欄に「羅盤」。
パックの作り直し：`python apps/lopan/engine/tools/make_dict_pack.py`（Raw から自動で作る。手で書かない）。

## 3. 羅盤エンジンの状態（実際に動かした結果。層01〜10 は作り直し中）

| 状態 | 層 |
|---|---|
| 引ける | 10〜13、23（隙間あり）、24、25、26、27 |
| 一部だけ（Raw に最初の区分しか角度がない） | 14、19、20、21 |

引けない層は、**エンジンの不具合ではなく、Raw にまだ角度が入っていない**のが原因。
詳細：`apps/lopan/docs/LAYER_DATA_STATUS.md`（自動生成）。人の確認が要る記録：層25の48番（角度が逆向きに入力）、層26・27（記号が一周の360件を超えている）。

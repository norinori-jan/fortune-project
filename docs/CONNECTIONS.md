## 2. いま動いているつながり（確認済み）

| つながり | 中身 | 確認 |
|---|---|---|
| Raw → 読み込み | `engine/lopan_service.py` が Raw（層10〜27）を読む | 17層を読み込めた（層27のみ未対応） |
| 角度 → 各層の記載 | `measure(330.0)` | 層10〜13・24・26 で引ける（§3） |
| 羅盤 → 知識辞書 | `data/dict-pack_lopan.json`（19件）を辞書に入れる | 知識辞書に取り込み、「羅盤」「層10」「measure」で検索できた（19件・JSエラーなし） |
| 羅盤 → ai-hub | 同じ辞書パック形式（dict-pack v1）。ai-hub が読む辞書パックに混ぜる | 形式は同じ。ai-hub での読み込みは **未確認** |

### 辞書に入れる手順（知識辞書）
設定 → 辞書パック → ファイルを選ぶ → `dict-pack_lopan.json`。入ったら、検索欄に「羅盤」。
パックの作り直し：`python apps/lopan/engine/tools/make_dict_pack.py`（Raw から自動で作る。手で書かない）。

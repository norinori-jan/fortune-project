## 見つけて直したこと
1. **`/fortune/query`（AI 呼び出し）が、BOM つきの JSON を読んで落ちていた**（`fortune-registry/prompts/*.json` が BOM つき）。`utf-8-sig` で読むよう修正。AI の問い合わせ全体が、以前から壊れていた可能性が高い。
2. **`/fortune/query` が誰でも無制限に呼べた**（サーバーの API キーで AI を呼ぶので、費用が膨らむ恐れ）。IP ごとに 1 時間 30 回までに制限（環境変数 `FORTUNE_QUERY_PER_HOUR` で変更可）。質問は 1000 文字まで。
3. **リクエストの大きさに上限が無かった** → 64KB を超えると 413 で断る。
4. 四柱の節入り前後の注意表示（前回）。
